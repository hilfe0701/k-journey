**분포는 그대로 `뒤집힘 13 · 유효 9 · 보강 12 · 불명 1 = 35`다.** 바뀌면 네가 틀린 것이다.

## 고칠 곳 5개

### 1. §1 주석 (`v3:80`) — `DEC-026`을 통째로 미확정이라고 적었다

현재: 「`DEC-026`·`DEC-027`은 … 확정되지 않은 상태다」

`DEC-027`은 통째로 미확정이 맞다. **`DEC-026`은 아니다.**
`DEC-026`은 **삭제분이 확정(유지)**이고 **신설분(`save_failed`·`E8`)만 미확정**이다.
주석을 **두 DEC을 갈라서** 다시 써라.

### 2. §3 `DESIGN.md` §21 행 (`v3:184`) — 「확정되기 전까지는 잠정 뒤집힘」

현재: 「DEC-026이 확정되기 전까지는 잠정 뒤집힘이다」 → **틀렸다.**
`DESIGN.md` §21의 원격 sync visual을 걷어내는 것은 **확정된 삭제분**이다. **잠정이 아니다.**
「**삭제분 적용 = 확정. §21의 원격 sync visual은 걷어낸다**」로 바꿔라.

### 3. §3 `docs/ERROR_MESSAGES.md` 결론 (`v3:207`) — 미확정 신설을 구현하라고 적었다

현재: 「`save_failed`/`E8`의 새 문구도 … 추가해야 한다」 → **미확정분을 구현 지시로 적었다.**
「`auth-*`·`network-offline-recovered`·`bucket-conflict` 등 **삭제분에 걸린 행은 걷어낸다(확정)**.
`save_failed`·`E8`의 새 문구는 **미확정이므로 이번에 추가하지 않는다**」로 바꿔라.

### 4. `src/lib/share.ts`를 `ADR-0034` 귀속에서 뺀다 (`v3:77` · `v3:200`)

§2 상세는 이미 「`share.ts`는 사진 업로드 코드가 아니다」로 맞게 적었다.
그런데 **§1 표의 코드 영향(`:77`)과 §3 목록(`:200`)에는 `ADR-0034` 항목으로 그대로 남아 있다.**

- `src/lib/share.ts` = 병풍 이미지를 OS share sheet로 내보내는 코드
  (「**Capture-and-share helpers for the byeongpung gallery**」 · `src/lib/share.ts:1-6`)
- `ADR-0034`가 지목한 target 4개(`photoUpload.ts` · 사진 UI 2개 · `storage.rules`)는 **전부 부재**

**두 곳에서 `ADR-0034` 귀속을 빼라.** 대신 **`DEC-024`(병풍 `Won't`) 영향**으로 옮겨라.
**업로드 제거 범위와 로컬 OS 공유 범위를 함께 걷어내면 안 된다.**

### 5. 되돌릴 조건을 「누적 필요조건」으로 쓴 것을 고친다 (`v3:166` · `v3:175`)

현재 `ADR-0030`은 `DEC-001`의 세 신호를, `ADR-0034`는 `DEC-022`의 여섯 신호를
**「함께 필요」·「함께 확인」**으로 적었다. **원문이 그런 구조가 아니다.**

원문의 각 신호는 **발동하면 해당 대안을 재검토한다**는 **개별 분기**다. 전부 충족해야 하는 것도 아니고,
충족했다고 기존 ADR이 자동 부활하는 것도 아니다.
- `DEC-001` 필드 10은 세 신호 **각각에** 「대안 A를 재검토한다」로 적혀 있다
  (`.work/pmjob/k-journey/28-k-journey-service-policy-2026-07-25.md:42`)
- `DEC-022` 필드 10은 **신호별로 다시 여는 대상이 다르다** — ①② 푸시 · ③ `DEC-001` 되돌림 · ④ 감사 로그 ·
  ⑤ 역할 분리 · ⑥ OTA 판정 (`.work/pmjob/k-journey/31-k-journey-decision-log-2026-07-25.md:434`)
- `ADR-0034`의 UID 사진 업로드에 직접 걸리는 것은 **③뿐**이고, **그 뒤에도 사진 서버 저장을 허용하는 새 결정이 필요하다**

**「신호 관측 → 해당 결정 재검토 → 새 결정 확정」 3단을 구분해서 쓰고**,
어느 신호가 어느 범위를 여는지 적어라. **하나도 자동 부활 조건이 아니다.**

### 6. `v3:299`의 파일명 오류

`.work/adr-dec-raw-v1.md`는 **없는 파일**이다. v1의 실제 이름은 **`.work/adr-dec-raw.md`**다.
`.work/`에 실재하는 것은 `adr-dec-raw.md` · `adr-dec-raw-v2.md` · `adr-dec-raw-v3.md`다.
