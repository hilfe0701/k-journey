## §2 통과한 것

- v1 지적 #1·#2·#3·#5·#6·#7·#8·#9는 위 표와 같이 해소됐다. #4만 과잉 반영이며, 그 원인은 제 v1 근거 오류다.
- 새 상세 6건 모두 `뒤집힘`을 ADR 파일·화면 ID 삭제로 쓰지 않았다. ADR-0008·0009·0011은 DEC-024의 `Won't`와 화면 ID 존치를 정확히 구분했고, ADR-0030·0034도 구현 근거 격리로 표현했다. ADR-0010도 ADR 삭제를 지시하지는 않는다.
- DEC-024 필드 10의 세 조건 문구는 6건 어디에도 새로 지어 넣은 표현이 없었다. ADR-0008·0009·0011에는 직접 맞는다. ADR-0010의 연결 오류와 ADR-0030·0034의 조건 불완전성은 §1에 적었다.
- 새 상세 6건에 문자열로 나열된 고유 파일 경로 22개는 모두 실제로 존재했다. 다만 ADR-0034의 `src/lib/share.ts` 역할 오귀속과 실제 target 부재 생략은 통과시키지 않았다.
- `docs/` 파급은 7개 후보 행 중 7행, 고유 문서 5개를 직접 열었다. `docs/ANALYTICS_SCHEMA.md`의 auth·mission·panel·gallery·photo 이벤트(`:20,28,34,48-49,66,153-162`), `DESIGN.md`의 mission/panel·photo upload·sync visuals(`:216-231,644-674,697-713`), `docs/PUSH_COPY.md`의 panel unlock catalog·priming·tests(`:57-69,98-125`), `docs/EMPTY_STATES.md`의 gallery·byeongpung 상태(`:74-113`), `docs/PLAY_DATA_SAFETY.md`의 계정 수집과 no-Storage 문장(`:8-40`)이 v2 설명과 일치했다.
- `해당 DEC 없음` 10행은 DEC-002~027의 결정 축과 정책서 DEC-001을 대조했다. ADR-0001·0016·0017·0019·0020·0024·0026·0027·0035의 9행은 해당 축을 교체하는 DEC가 없고, 재설계와 무관한 기술·스타일·테스트·빌드 규칙이므로 `유효`를 수용한다. ADR-0007만 §1 #2와 같이 통과하지 못했다.
- §6에는 작성 레인의 이의가 없어서 반대 논리의 타당성을 따로 판정할 항목도 없다. 다만 이의 유무와 별개로, 제 v1 지적 #4의 DEC-003·018 연결은 틀렸다고 이 검수에서 바로잡았다.
- §7의 직접 ADR 매핑은 `DEC-026 → ADR-0031`, `DEC-027 → ADR-0004·0005`로 맞고, 추가로 빠진 직접 ADR 의존은 찾지 못했다. 나머지 뒤집힘의 구현 격리는 확정된 DEC-001·022·024로 판단할 수 있다. DEC-026 내부의 확정 경계만 §1 #5처럼 고쳐야 한다.

## §3 검수의 한계

- 이 검수는 v1→v2 델타만 보았다. 제3자가 완료한 표 35행, ID 집합, 분포, 인용 70셀 실재 검사는 반복하지 않았다.
- `docs/` 파급 목록은 고유 문서 5개, 후보 표 7행만 표본 확인했다. §3의 긴 전체 문서 목록에 든 나머지 파일을 모두 다시 열지는 않았다.
- 경로 검사는 새 상세 6건에 적힌 고유 경로 22개의 존재 여부와 ADR-0034 target 부재를 확인했다. 각 경로의 모든 호출 관계를 전건 추적하지는 않았다.
- `해당 DEC 없음` 10행은 DEC 제목·결정 축과 관련 키워드, 각 ADR의 문제·선택을 대조했다. 신 설계의 모든 요구사항 문서가 이 10개 기술 결정을 암묵적으로 바꾸는지까지 전수 정독한 것은 아니다.
- `DEC-025`도 미확정이지만 이번 ADR 표에서 그 결정에 직접 기대는 행은 찾지 못했다. 분석 지표 설계 자체를 구현할 때는 DEC-027과의 종속을 별도로 처리해야 한다.

## 최종 답

**조건부 가능.** 다음 조건을 모두 충족한 뒤에만 이 대조를 근거로 `CLAUDE.md`를 고치고 구현에 들어갈 수 있다.

1. ADR-0010의 근거를 DEC-003·018 교체가 아니라 DEC-024의 `MEM-01 Won't`로 바꾸고, `CLAUDE.md:94-98`에 4종 주거 × 명의 규칙을 이식하라는 제안을 제거한다. 신 행정 서류 모델은 별도 현재 규칙으로 둔다.
2. ADR-0007을 `불명`으로 내리거나, 병풍·AuthGate와 독립적으로 cold-start splash가 필요한 현재 요구/결정을 먼저 확정한다. 그 전에는 이 ref를 구현 규칙으로 고정하지 않는다.
3. DEC-026은 기존 원격 sync 상태·전이 삭제를 적용하고, `save_failed`·`E8` 신설만 별도 세션 확정 전까지 격리한다. DEC-027 의존 analytics payload/cohort도 확정 전까지 격리한다.
4. ADR-0034 상세에서 실제 없는 upload target과 실재하는 OS share 코드를 구분하고, ADR-0030·0034의 되돌림에는 DEC-001·022가 함께 필요한 부분을 명시한다.

**기각 0건이 아니다.** 새 지적은 차단 3건·보강 2건이다. 실제로 새 상세 6건, `해당 DEC 없음` 10행, `docs/` 후보 7행(고유 5파일), §7 의존 3행을 열어 보았다. 그리고 제 v1 지적 중 #4의 DEC-003·018 연결은 틀렸음을 명시적으로 철회·정정한다.
