## 절대 규칙 4개 — 어기면 산출물이 무효다

1. **숫자는 눈으로 세지 마라.** ADR 개수와 DEC 개수는 **명령으로 세고, 센 명령을 산출물에 그대로 적어라.**
   내가 「ADR 37건 · DEC 27건」으로 알고 있는데 **그 값이 맞는지 네가 확인해라.** 다르면 다르다고 적어라.
2. **모르면 `불명`으로 둬라.** 그럴듯한 판정을 지어내지 마라. `불명`에는 **무엇을 더 봐야 알 수 있는지**를 적어라.
3. **양쪽 원문을 인용해라.** 판정마다 ADR 쪽 문장과 DEC 쪽 문장을 **각각 그대로** 옮겨라. 요약하지 마라.
4. **누락을 만들지 마라.** ADR 전건이 표에 나와야 한다. 「나머지는 무관」으로 뭉뚱그리지 마라.

## 판정 4종 — 이 중 하나로만 분류한다

| 판정 | 뜻 |
|---|---|
| **`뒤집힘`** | 신 `DEC`이 이 ADR의 결정을 **무효화**한다. 그대로 두면 구현이 틀린다 |
| **`유효`** | 재설계와 무관하거나, 신 설계에서도 그대로 성립한다 (예: 보안·접근성·i18n 결정) |
| **`보강`** | 신 `DEC`이 ADR을 **뒤집지 않고 더 구체화**한다. 둘 다 살아 있다 |
| **`불명`** | 판정에 필요한 근거가 없다. **무엇을 더 봐야 하는지 적는다** |

## 산출물

`.work/adr-dec-raw.md` 하나에 쓴다. 다른 파일은 만들지 마라.

### §0 집계 — 명령과 결과를 같이 적는다

```
ADR 개수: <명령> → <결과>
DEC 개수: <명령> → <결과>
판정 분포: 뒤집힘 N · 유효 N · 보강 N · 불명 N (합계가 ADR 개수와 같은지 확인)
```

### §1 대조표 — ADR 전건

| ADR ID | ADR 제목 | 판정 | 충돌/관련 DEC | ADR 원문 | DEC 원문 | 코드 영향 |
|---|---|---|---|---|---|---|

- **코드 영향**: 이 ADR이 살아 있는 코드 경로(`src/…`·`app/…`·`docs/…` 파일명). 모르면 `불명`
- 판정이 `뒤집힘`인 행은 **표 아래에 별도 절**로 근거를 길게 적어라

### §2 `뒤집힘` 상세

`뒤집힘` 각 건에 대해:
- 무엇이 무효가 되는가
- 그 ADR을 근거로 짜인 코드·문서가 무엇인가
- 신 `DEC`이 요구하는 방향이 무엇인가
- **되돌릴 조건** — 어떤 사실이 나오면 ADR 쪽이 옳게 되는가

### §3 `docs/` 파급

`뒤집힘` ADR을 근거로 삼는 `docs/` 파일 목록. 특히 아래는 **반드시 확인해라**:
`docs/ANALYTICS_SCHEMA.md` · `docs/EMPTY_STATES.md` · `docs/SETTINGS.md` · `docs/PUSH_COPY.md` ·
`docs/ERROR_MESSAGES.md` · `docs/PLAY_DATA_SAFETY.md` · `docs/STORE_LISTING.md` · `DESIGN.md`

이미 알려진 충돌 후보 3개다. **참이라고 전제하지 말고 확인해라. 아니면 아니라고 적어라.**
- `docs/ANALYTICS_SCHEMA.md`의 `KJEvent` 스키마 ↔ `DEC-027`(분석 이벤트 해상도 규칙) · `POL-001`(조건 축 전송 금지)
- `DESIGN.md` §21 「Offline & sync conflict visuals」 ↔ `DEC-026`(축 2 동기화 전제 삭제)
- `docs/PLAY_DATA_SAFETY.md` · `STORE_LISTING.md` ↔ `POL-012`(스토어 개인정보 고지)

### §4 저장소 `CLAUDE.md` 개정 제안

저장소 루트 `CLAUDE.md` 4행이 이렇게 적혀 있다:

> *"It encodes decisions that have already been made. Don't relitigate them."*

**이 문장은 재설계를 막는다.** §1 판정 결과에 근거해서, `CLAUDE.md`의 어느 줄을
어떻게 고쳐야 하는지 **줄 단위로** 제안해라. **파일을 직접 고치지는 마라 — 제안만 적어라.**

`CLAUDE.md`가 「ADR 35건」이라고 적고 있는데 실제 개수와 맞는지도 확인해서 적어라.

### §5 네가 막힌 곳

판정을 못 한 것, 근거가 모자란 것, 두 문서가 서로 다른 낱말로 같은 것을 가리켜 헷갈린 것을
**숨기지 말고 전부 적어라.** 이 절이 비어 있으면 오히려 의심스럽다.
